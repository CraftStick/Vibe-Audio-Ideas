# Vibe Audio Ideas

[English](README.md) · [Русский](README.ru.md)

Прототип в стиле vibe coding: приложение для быстрых голосовых заметок.

## Возможности

- Запись аудио с микрофона
- Автоматическая черновая расшифровка речи (если поддерживается браузером)
- Локальное сохранение заметок в браузере
- Воспроизведение и удаление сохранённых заметок

## Начало работы

Откройте `index.html` в браузере. Для более стабильной работы микрофона лучше запустить локальный сервер:

```bash
python3 -m http.server 8000
```

Затем откройте <http://localhost:8000>.

## Использование

1. Разрешите доступ к микрофону.
2. Нажмите «Начать запись», затем «Остановить» и «Сохранить заметку».
